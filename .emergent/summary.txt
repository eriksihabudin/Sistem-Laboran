The system should have the following key modules:
1.  **Dashboard**: Provides a summary overview, including item counts (total, normal, damaged), active loans, and graphs for monthly loans and item damage. It should also display the latest borrowers.
2.  **Inventory Management**: A comprehensive list of all items with photos, filtering (by status, category), and search. It must support adding, editing, and deleting items. A detailed view for each item should show its specifications, loan history, and damage history.
3.  **Loan Management**: Allows technicians to record new loans, including borrower details and uploading a loan letter. It features a list of all ongoing and past loans. The process includes marking items as returned, with options to note the return condition.
4.  **Reporting**: Generate and view tabular reports for inventory status (normal, damaged) and monthly loans. This section must include search, filtering by date/month/year, and a print function.
5.  **Settings**: Manage item categories (add, edit, delete) and sync them across the application, including forms and dashboard charts.

The user experience should be simple and efficient for lab technicians. The UI should be modern, clean, and use color-coded badges for status indicators (e.g., green for 'Normal', red for 'Rusak').
